# snel-studio

One good template per video style, built once, used by every reel.

**Why:** we went straight from a style test to production, so every shot reinvents the world, light,
characters and camera. That is where the inconsistency comes from. A template fixes the look once.

**How a reel uses it:** stills first (Loc approves at a glance), then render. Tweaks are knobs
(camera speed, light, blur), not new prompts.

**Templates:**
- `toon-2d`: first
- `code-explainer`: later

Status: empty. Spar first, then build.
